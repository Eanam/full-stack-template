# Go Micro

## 仓库链接

- [micro/go-micro](https://github.com/micro/go-micro)
- 官方文档：[micro.dev](https://micro.dev/)

## 仓库总结

- 定位：提供服务发现、RPC、消息和存储等能力的 Go 服务框架，同时提供 `micro` CLI 和 Agent/服务开发工作流。
- 核心技术栈：Go、RPC、服务注册与发现、消息传递、可插拔存储、CLI 代码生成和运行时编排。
- 脚手架能力：可通过 `micro` CLI 从项目目录或自然语言描述生成服务，并用 `micro run` 启动多服务项目、热更新、网关和控制台。
- 工程能力：组件可插拔，支持服务间调用、消息、工作流和 Agent 工具化调用。
- 适用场景：需要快速组合多个 Go 服务，或同时构建服务与 Agent 工作流的项目。
- 优点：从初始化、生成到运行的 CLI 体验完整，服务基础设施抽象统一。
- 注意事项：当前主线 README 已明显融合 Agent 能力；传统微服务项目应确认所用主版本、插件和运行时依赖是否符合团队架构。
- 许可证：Apache-2.0。
