# Nuxt

## 仓库链接

- [nuxt/nuxt](https://github.com/nuxt/nuxt)
- 官方文档：[nuxt.com](https://nuxt.com/)

## 仓库总结

- 定位：基于 Vue 的生产级全栈 Web 框架，统一前端渲染、服务端路由和部署能力。
- 核心技术栈：Vue、TypeScript、Nitro、SSR、SSG、Hybrid Rendering、自动路由、Server API 和 Nuxt Modules。
- 脚手架能力：执行 `npm create nuxt@latest <my-project>` 创建带依赖和基础文件的 Nuxt Starter，也可使用 `nuxt.new` 在线启动。
- 工程能力：服务端 `server/` 目录、自动导入、数据获取、SEO、代码分割、边缘部署和模块生态。
- 适用场景：Vue 团队构建需要 SSR、SEO、服务端 API 或混合渲染的全栈网站和应用。
- 优点：前后端目录和运行时统一，初始化简单，部署目标覆盖面广。
- 注意事项：Nuxt 版本、Nitro 运行时和部署平台需要配套验证；复杂业务仍需自行确定数据库、认证和权限方案。
- 许可证：MIT。
