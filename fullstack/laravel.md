# Laravel Application Skeleton

## 仓库链接

- [laravel/laravel](https://github.com/laravel/laravel)
- 官方文档：[laravel.com/docs](https://laravel.com/docs)

## 仓库总结

- 定位：Laravel 官方 PHP 应用基础骨架，为新 Laravel Web 应用提供约定好的目录、配置和启动文件。
- 核心技术栈：PHP、Laravel、Eloquent ORM、路由、依赖注入、数据库迁移、队列、缓存、Session 和事件广播。
- 脚手架能力：通过 Laravel Installer 或 Composer 创建新应用，再结合官方 Starter Kits 选择 Blade、Livewire、React/Vue/Inertia、认证和前端构建方案。
- 工程能力：配置和环境文件、服务容器、数据库迁移、队列/任务、缓存、事件、测试和生产部署基础。
- 适用场景：需要成熟 PHP 全栈生态，快速搭建管理后台、业务系统、内容站点或 API + SPA 应用的团队。
- 优点：约定完整、官方生态成熟，后端和前端 Starter Kit 组合灵活。
- 注意事项：`laravel/laravel` 本身是基础骨架，不包含完整认证和业务模块；应根据项目选择官方 Starter Kit，并固定 PHP/Laravel 版本。
- 许可证：MIT。
