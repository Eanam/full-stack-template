## 仓库总结

- 定位：交互式 CLI，用于创建全栈、类型安全的 Next.js 应用。
- 核心技术栈：Next.js、TypeScript、tRPC、Tailwind CSS、Prisma/Drizzle 和 NextAuth.js。
- 脚手架能力：执行 `npm create t3-app@latest`，按提示选择数据库、认证、API 和样式方案，生成按需组合的 T3 Stack 项目。
- 工程能力：前后端类型安全、模块化配置、服务端 API、数据库 ORM、认证和 Tailwind 基础设施。
- 适用场景：希望使用 TypeScript 端到端开发现代 Web/SaaS 应用，并避免从空 Next.js 项目手工拼装基础设施的团队。
- 优点：选项式生成、类型安全优先、技术栈组合清晰，适合快速启动和持续演进。
- 注意事项：它不是“全家桶”模板，状态管理、部署和复杂业务能力需要团队自行选择；生成后应锁定 Next.js、ORM 和认证版本。
