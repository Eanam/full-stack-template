# RedwoodSDK

## 仓库链接

- [redwoodjs/sdk](https://github.com/redwoodjs/sdk)
- 官方文档：[docs.rwsdk.com](https://docs.rwsdk.com/)

## 仓库总结

- 定位：运行在 Cloudflare 平台上的 Server-first React 全栈框架，以 Vite 插件、React Server Components 和 Server Functions 为核心。
- 核心技术栈：React、Vite、React Server Components、Server Functions、类型安全路由、Cloudflare Workers、D1、R2、Durable Objects 和 Queues。
- 脚手架能力：执行 `npx create-rwsdk my-project-name` 创建项目，安装依赖后即可启动开发服务器。
- 工程能力：服务端路由、中间件、请求/响应 Web 标准、实时能力和 Cloudflare 原生服务集成。
- 适用场景：目标部署到 Cloudflare Workers，并希望采用 Server-first React 和边缘运行时的全栈项目。
- 优点：初始化快速，Web 标准基础清晰，Cloudflare 服务集成路径直接。
- 注意事项：平台绑定明显，采用前需要评估 Cloudflare 运行时限制、数据库方案和迁移成本；该项目是 Redwood 生态的新方向，需关注版本变化。
- 许可证：MIT。
