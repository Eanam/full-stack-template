# Wasp

## 仓库链接

- [wasp-lang/wasp](https://github.com/wasp-lang/wasp)
- 官方文档：[wasp.sh/docs](https://wasp.sh/docs)

## 仓库总结

- 定位：面向 React、Node.js 和 Prisma 的声明式、全栈框架，使用高层应用规范减少重复代码。
- 核心技术栈：Wasp DSL、React、Node.js、Prisma、TypeScript/JavaScript，以及可选的认证、任务和邮件能力。
- 脚手架能力：通过 Wasp CLI 创建应用，使用 `.wasp.ts` 描述路由、页面、查询、实体和认证，再生成可检查和修改的全栈代码。
- 工程能力：内置认证、RPC/查询、后台任务、邮件、端到端类型安全和单命令部署。
- 适用场景：希望快速构建 CRUD、SaaS、后台管理或 AI Web 应用，并接受较强约定的团队。
- 优点：全栈抽象层次高，生成代码可接管，常见基础设施集成成本低。
- 注意事项：框架 DSL 和生成流程带来学习成本；采用前应验证生成代码、部署平台和 Prisma 版本是否符合团队运维要求。
- 许可证：MIT。
