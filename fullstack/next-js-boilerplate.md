# Next.js Boilerplate

## 仓库链接

- [ixartz/Next-js-Boilerplate](https://github.com/ixartz/Next-js-Boilerplate)
- 在线 Demo：[demo.nextjs-boilerplate.com](https://demo.nextjs-boilerplate.com)

## 仓库总结

- 定位：面向 Next.js 的生产级 Web/SaaS Boilerplate，包含前端、数据库、认证、测试和质量工具链。
- 核心技术栈：Next.js App Router、TypeScript、Tailwind CSS、Drizzle ORM、PostgreSQL/SQLite/MySQL、Clerk、Sentry、Vitest、Playwright 和 Storybook。
- 脚手架能力：克隆仓库后替换项目配置即可作为新 Next.js 应用起点，官方 Demo 展示了可运行的认证系统。
- 工程能力：ESLint、Prettier、Lefthook、Lint-staged、Commitlint、多语言、数据库迁移、单元测试、E2E 测试和组件文档。
- 适用场景：需要快速启动带认证、数据库和后台界面的 Next.js SaaS 或内容型全栈应用的团队。
- 优点：工程化覆盖面广，减少重复配置，适合作为团队模板或内部二次封装基础。
- 注意事项：预置第三方服务较多，正式使用前应替换 Clerk/Sentry/Neon 等服务配置，并裁剪不需要的依赖。
