# uni-app

## 仓库链接

- [dcloudio/uni-app](https://github.com/dcloudio/uni-app)
- 官方文档：[uniapp.dcloud.io](https://uniapp.dcloud.io/)

## 仓库总结

- 定位：基于 Vue 的跨端应用框架，一套代码可发布到 iOS、Android、鸿蒙、Web 和多种小程序平台。
- 核心技术栈：Vue、JavaScript/TypeScript、uni-app/uni-app x、UTS，以及 DCloud 的多端编译和运行时。
- 脚手架能力：提供 uni-app 工程模板、示例项目和 CLI/HBuilderX 创建路径，可从 Vue 项目快速生成多端应用。
- 工程能力：多端条件编译、插件生态、原生插件扩展、App 和小程序发布链路；`uni-app x` 进一步提供原生渲染路线。
- 适用场景：以 Vue 为主，希望同时覆盖 App、小程序和 Web，尤其是国内多小程序平台的产品团队。
- 优点：目标平台覆盖面广，Vue 开发者迁移成本低，国内生态和插件资源丰富。
- 注意事项：`uni-app` 与 `uni-app x` 是不同技术路线，需在项目初期明确选择；各平台运行时差异仍需通过真机和目标平台工具验证。
- 许可证：Apache-2.0。
