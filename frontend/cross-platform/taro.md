# Taro

## 仓库链接

- [NervJS/taro](https://github.com/NervJS/taro)
- 官方文档：[docs.taro.zone](https://docs.taro.zone/)

## 仓库总结

- 定位：开放式跨端跨框架解决方案，可用 React、Vue 或 Nerv 构建小程序、H5 和 React Native 应用。
- 核心技术栈：Node.js、TypeScript、React/Vue/Nerv、Taro CLI，以及各平台小程序和 Web 构建链路。
- 脚手架能力：通过 Taro CLI 初始化项目，并根据目标端生成对应工程和构建配置；官方提供 5 分钟上手指南和示例生态。
- 工程能力：多端编译、跨端组件、插件和物料市场，覆盖微信、京东、百度、支付宝、字节跳动、QQ 小程序、H5 和 React Native 等端。
- 适用场景：需要以 React/Vue 技术栈同时交付小程序、H5 和部分原生应用端的团队。
- 优点：国内小程序端覆盖广，跨端编译模型成熟，前端团队上手成本较低。
- 注意事项：不同端的 API、组件和能力存在差异，需要明确端能力边界并维护条件编译代码；仓库 API 未识别到标准 SPDX 许可证，采用前应核对仓库 LICENSE。
- 许可证：GitHub API 当前显示 `NOASSERTION`，请以仓库实际 LICENSE 文件为准。
