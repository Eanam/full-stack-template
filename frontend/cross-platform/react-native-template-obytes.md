# React Native Template Obytes

## 仓库链接

- [obytes/react-native-template-obytes](https://github.com/obytes/react-native-template-obytes)
- Starter 站点：[starter.obytes.com](https://starter.obytes.com/)

## 仓库总结

- 定位：面向 Expo/React Native 的生产级 Starter Kit，优先考虑开发体验、性能和团队一致性。
- 核心技术栈：Expo、React Native、TypeScript、Expo Router、NativeWind/TailwindCSS、React Query、TanStack Form、Zustand、Jest 和 Maestro。
- 脚手架能力：提供可直接复制的应用模板和完整工程配置，覆盖环境变量、EAS、GitHub Actions、代码检查、测试和多环境构建。
- 工程能力：认证流程、路由、表单、数据请求、本地存储、国际化、单元测试和端到端测试基础设施。
- 适用场景：希望采用 Expo 作为 React Native 推荐工作流，并快速获得接近生产环境的项目基线的团队。
- 优点：开箱即用能力强，工程化配置覆盖面广，适合团队统一项目实践。
- 注意事项：预置依赖较多，使用前应按业务裁剪；Expo SDK、React Native 和原生构建服务版本需要协同升级。
- 许可证：MIT。
