- [thecodingmachine/react-native-boilerplate](https://github.com/thecodingmachine/react-native-boilerplate)

## 仓库总结

- 定位：面向 React Native 移动应用的通用工程起步模板，强调分层和关注点分离。
- 核心技术栈：React Native、JavaScript/TypeScript、React Native CLI，以及模板自身的架构约定。
- 脚手架能力：可使用 `npx @react-native-community/cli@latest init MyApp --template @thecodingmachine/react-native-boilerplate` 初始化新项目。
- 工程能力：预置应用架构、文档、Metro 启动流程和 Android/iOS 运行配置，减少从空项目搭建的工作量。
- 适用场景：需要 React Native CLI 工作流，并希望从明确的生产应用结构开始开发的团队。
- 优点：模板化初始化命令清晰，架构说明完整，适合作为团队项目基线参考。
- 注意事项：模板版本需与 React Native CLI、Node、Android SDK 和 Xcode 版本匹配；引入后应审查预置依赖和架构是否符合团队规范。
- 许可证：MIT。
