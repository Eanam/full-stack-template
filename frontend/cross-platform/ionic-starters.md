# Ionic Starter Templates

## 仓库链接

- [ionic-team/starters](https://github.com/ionic-team/starters)
- 官方文档：[Ionic Getting Started](https://ionicframework.com/docs)

## 仓库总结

- 定位：Ionic CLI 使用的官方项目 Starter 集合，用于快速初始化 Angular、React 或 Vue 的 Ionic 应用。
- 核心技术栈：Ionic、Angular/React/Vue、Vite 或对应 CLI 构建工具，以及 Cordova/Capacitor 集成路线。
- 脚手架能力：仓库直接提供 base 和 official starter 模板，Ionic CLI 可据此创建应用并选择目标前端框架。
- 工程能力：预置多种 UI 起步结构，支持通过 Capacitor/Cordova 打包移动端，也可发布为 Web/PWA。
- 适用场景：Web 团队希望复用 HTML/CSS/JavaScript 技能构建 iOS、Android 和 PWA 应用的项目。
- 优点：官方 starter 与 CLI 集成，前端框架选择灵活，适合快速验证和混合开发。
- 注意事项：原生能力和性能高度依赖 Capacitor/Cordova 插件；仓库同时保留历史 starter，初始化时应选择当前 CLI 版本对应的模板。
- 许可证：MIT。
