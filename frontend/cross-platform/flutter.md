# Flutter

## 仓库链接

- [flutter/flutter](https://github.com/flutter/flutter)
- 官方文档：[flutter.dev](https://flutter.dev/)

## 仓库总结

- 定位：Google 基于 Dart 的跨平台 UI SDK，可从一套代码构建 iOS、Android、Web、桌面和嵌入式应用。
- 核心技术栈：Dart、Flutter Widgets、Skia/Impeller、平台插件和原生互操作能力。
- 脚手架能力：Flutter SDK 自带 CLI，可使用 `flutter create <project-name>` 创建标准应用工程，并通过模板参数初始化不同项目形态。
- 工程能力：热重载、统一渲染体系、Material/Cupertino 组件、插件生态、测试和多平台构建工具链。
- 适用场景：希望以 Dart 和统一 UI 代码覆盖移动端，并同时兼顾 Web 或桌面端的产品团队。
- 优点：官方工具链完整，跨平台 UI 一致性高，生态和社区规模大。
- 注意事项：复杂原生能力仍需编写平台插件；升级 Flutter/Dart 版本时应验证插件兼容性和 iOS/Android 构建环境。
- 许可证：BSD-3-Clause。
