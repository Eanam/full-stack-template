# Kotlin Multiplatform App Template

## 仓库链接

- [Kotlin/KMP-App-Template](https://github.com/Kotlin/KMP-App-Template)
- 官方模板入口：[kmp.jetbrains.com](https://kmp.jetbrains.com/)

## 仓库总结

- 定位：JetBrains/Kotlin 官方 Kotlin Multiplatform 应用模板，采用共享业务逻辑、数据处理和 Compose Multiplatform 共享 UI。
- 核心技术栈：Kotlin Multiplatform、Compose Multiplatform、Gradle、Ktor、kotlinx.serialization、Koin。
- 脚手架能力：提供 Android、iOS、桌面和 Web 的可运行示例工程，可通过官方模板入口或复制仓库作为项目起点。
- 工程能力：多平台 source set、共享网络和序列化代码、Compose Navigation、依赖注入，以及各平台运行配置。
- 适用场景：希望最大化 Kotlin 代码共享，并使用 Compose Multiplatform 统一 UI 的 Android/iOS 跨端项目。
- 优点：官方维护，示例覆盖平台较广，能直接展示 KMP 项目结构和共享 UI 工作流。
- 注意事项：iOS 仍依赖 macOS/Xcode；模板中的示例依赖和架构不应未经评估直接作为生产标准。
- 许可证：Apache-2.0。
