# Jetpack Compose Samples

## 仓库链接

- [android/compose-samples](https://github.com/android/compose-samples)
- 官方文档：[Jetpack Compose](https://developer.android.com/jetpack/compose)

## 仓库总结

- 定位：Android 官方 Jetpack Compose 样例集合，覆盖从低复杂度到高级场景的多个独立 Android Studio 项目。
- 类型：样例集合，不是单一可定制脚手架；适合挑选 UI、导航、主题、动画、响应式布局和测试实现。
- 核心技术栈：Kotlin、Jetpack Compose、Material 3、Navigation、ViewModel、Coroutines、Room、动态主题和 UI 测试。
- 脚手架能力：可复制某个样例作为具体功能模块或界面起点，部分样例包含接近真实应用的项目结构。
- 工程能力：提供 JetNews、Jetchat、Jetsnack、Jetcaster、Reply、JetLagged 等不同复杂度和交互场景。
- 适用场景：需要快速验证 Compose UI 模式，或为新 Android 项目挑选局部实现参考的团队。
- 优点：官方示例与 Compose 文档同步，单个样例边界清晰，便于按能力检索和复用。
- 注意事项：不要把样例集合整体当作统一架构模板；复制代码前应确认样例的目标版本、依赖和生产适用性。
- 许可证：Apache-2.0。
