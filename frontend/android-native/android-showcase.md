# Android Showcase

## 仓库链接

- [igorwojda/android-showcase](https://github.com/igorwojda/android-showcase)

## 仓库总结

- 定位：社区维护的生产级 Android 应用参考工程，聚焦现代 Kotlin、Clean Architecture 和模块化。
- 核心技术栈：Kotlin 2.x、Jetpack Compose、Coroutines/Flow、Room、Retrofit、Coil、Koin、Gradle Kotlin DSL、Version Catalog。
- 脚手架能力：可 Fork 或复制其模块化目录、Convention Plugins、静态检查、CI/CD 和测试配置，作为中大型应用起步基线。
- 工程能力：Feature Modules、MVVM/MVI、依赖注入、架构约束测试、Ktlint/Detekt/Spotless、单元和 UI 测试，以及 Gradle 配置缓存。
- 适用场景：希望从社区生产实践出发，搭建可扩展、可测试的 Compose 多模块 Android 应用的团队。
- 优点：对 Gradle 工程化、模块边界和代码质量工具覆盖全面，适合研究企业级项目组织方式。
- 注意事项：它是完整示例应用而非参数化生成器，预置业务和依赖较多；采用前应评估 Koin、模块划分和质量工具是否符合团队标准。
- 许可证：MIT。
