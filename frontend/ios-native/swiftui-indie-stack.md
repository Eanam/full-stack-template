# SwiftUI Indie Stack

## 仓库链接

- [cliffordh/swiftui-indie-stack](https://github.com/cliffordh/swiftui-indie-stack)

## 仓库总结

- 定位：从真实生产应用提炼的 SwiftUI Starter，提供离线优先和可选云端能力。
- 核心技术栈：SwiftUI、UserDefaults、Firebase Auth/Firestore/Crashlytics（可选）、RevenueCat、TelemetryDeck、Widgets 和 Swift Package/原生 Xcode 工程。
- 脚手架能力：克隆项目后可在 Local Mode 下无需 Firebase 运行，也可切换 Cloud Mode 接入认证、同步和云函数。
- 工程能力：认证、订阅、分析、CMS 内容、主题系统、Widget、Onboarding，以及按功能组织的 `TabBar`、`Auth`、`Library` 等目录。
- 适用场景：需要快速搭建带登录、内容、设置和底部 Tab 的 SwiftUI 产品原型或独立开发者应用。
- 优点：产品功能覆盖较完整，离线和云端模式可切换，已经包含常见 App 基础模块。
- 注意事项：RevenueCat、TelemetryDeck 和 Firebase 等第三方服务需要单独配置；使用前应删除不需要的产品功能和密钥占位配置。
- 许可证：MIT。
