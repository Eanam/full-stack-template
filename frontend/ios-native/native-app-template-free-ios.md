# NativeAppTemplate Free iOS

## 仓库链接

- [nativeapptemplate/NativeAppTemplate-Free-iOS](https://github.com/nativeapptemplate/NativeAppTemplate-Free-iOS)
- 配套 API：[nativeapptemplate/nativeapptemplateapi](https://github.com/nativeapptemplate/nativeapptemplateapi)

## 仓库总结

- 定位：现代 SwiftUI 产品型模板，包含用户认证和完整 CRUD 示例，可与配套 Rails API 自托管运行。
- 核心技术栈：Swift、SwiftUI、`@Observable`、MVVM 分层、Swift Testing、SwiftLint 和 Rails API。
- 脚手架能力：克隆后即可得到包含登录、注册、邮箱确认、密码找回、隐私条款和 CRUD 流程的完整应用基础。
- 工程能力：Onboarding、认证、版本/隐私/条款强制更新、网络 API 配置和共享 Xcode Scheme。
- 适用场景：需要以认证、列表和 CRUD 为核心的业务 App，或希望从完整产品流程而不是空白模板开始的团队。
- 优点：业务闭环完整，iOS 模板和后端 API 同时开源，适合快速验证真实业务流程。
- 注意事项：必须自行运行并配置 API；仓库当前要求较新的 iOS 版本，正式项目应先评估最低系统版本和后端部署方式。
- 许可证：MIT。
