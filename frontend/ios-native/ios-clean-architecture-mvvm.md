# iOS Clean Architecture MVVM

## 仓库链接

- [kudoleh/iOS-Clean-Architecture-MVVM](https://github.com/kudoleh/iOS-Clean-Architecture-MVVM)

## 仓库总结

- 定位：以 Clean Architecture 和 MVVM 为核心的 iOS 应用模板，示例业务为电影搜索。
- 核心技术栈：Swift、UIKit、SwiftUI、MVVM、Flow Coordinator、依赖注入、DTO 映射和响应缓存。
- 脚手架能力：可替换示例中的 Movie 业务名称，将 Domain、Data、Presentation 和 Infrastructure 层作为新项目基础。
- 工程能力：分页、网络请求、缓存、暗色模式、尺寸类别、单元测试、ViewModel 测试，以及 UIKit/SwiftUI 共用 ViewModel。
- 适用场景：需要经典分层架构，并希望逐步在 UIKit 项目中引入 SwiftUI 的团队。
- 优点：分层边界和依赖方向清晰，示例覆盖从网络到 UI 的完整业务链路。
- 注意事项：README 要求较旧的 Xcode 11/Swift 5 环境，采用前应评估升级到当前 Swift/Xcode 的成本；仓库许可证应以实际 LICENSE 文件为准。
