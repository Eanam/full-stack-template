# SwiftUI + TCA Template

## 仓库链接

- [ethanhuang13/SwiftUI-TCA-Template](https://github.com/ethanhuang13/SwiftUI-TCA-Template)
- TCA 官方仓库：[pointfreeco/swift-composable-architecture](https://github.com/pointfreeco/swift-composable-architecture)

## 仓库总结

- 定位：采用 The Composable Architecture 的 SwiftUI/macOS 模块化项目模板。
- 核心技术栈：Swift 6、SwiftUI、TCA、Swift Package Manager、iOS 17、macOS 14 和 XCTest/测试目标。
- 脚手架能力：提供可导入 Xcode 的应用 Target、本地 Swift Package、Features、Views、Models 和依赖客户端模块。
- 工程能力：Reducer 驱动的业务状态、依赖客户端抽象、Feature 测试、模块化构建和类型清晰的依赖关系。
- 适用场景：团队明确采用 TCA，并希望从模块化和可测试的 SwiftUI 工程开始开发 iOS/macOS 应用。
- 优点：模块边界清楚，状态管理和测试路径规范，适合复杂业务或长期维护项目。
- 注意事项：模板要求 iOS 17、macOS 14、Xcode 16 和 Swift 6；TCA 学习成本和架构约束高于普通 MVVM。
- 许可证：MIT。
